# 海曙区社会治理中心事件分析系统

## 项目概述

海曙区社会治理中心事件分析系统是一个专业的社会治理事件管理和分析平台，集成了事件查询、智能分析、人员画像、AI问答等多项功能。系统采用现代化的前后端分离架构，为海曙区社会治理工作提供数据驱动的决策支持。

### 系统特色

- 🔍 **智能检索** - 多维度搜索和筛选，快速定位目标事件
- 📊 **数据分析** - 事件聚类分析，发现关联性和规律
- 👥 **人员画像** - 全面人员行为分析和特征提取
- 🤖 **AI问答** - 基于事件数据的智能问答系统
- 📈 **统计报告** - 动态生成数据统计和可视化报告
- 🔐 **安全认证** - 完善的用户登录和权限管理

## 核心功能

### 🔐 用户认证系统
- **安全登录** - 用户名密码认证，支持记住登录状态
- **会话管理** - 自动检测服务状态，服务停止时自动退出登录
- **权限控制** - 未登录用户自动跳转到登录页面

### 📋 事件列表管理
- **数据展示** - 事件编号、描述、镇街名称、级别、分类、时间等关键信息
- **智能搜索** - 支持事件编号、描述、处置结果、报警人信息的模糊搜索
- **多维筛选** - 按镇街名称、事件级别、事件分类等条件筛选
- **分页浏览** - 高效的分页加载，支持大数据量展示

### 🔍 事件详情分析
- **详细信息** - 完整的事件描述、处理过程、结果等信息
- **关联分析** - 显示相关事件数量，支持跳转查看
- **时间轴展示** - 清晰的事件处理时间线
- **参与人统计** - 事件参与人员数量和信息分析

### 🔗 聚类事件分析
- **事件聚类** - 智能识别和展示关联事件群组
- **时间线视图** - 聚类事件的完整时间发展过程
- **持续时间计算** - 自动计算聚类事件的持续时间
- **参与人分析** - 聚类事件中的人员参与情况

### 👥 人员分析系统
- **人员画像** - 基于事件参与情况的人员行为分析
- **角色识别** - 自动识别人员在事件中的角色类型
- **关联事件** - 展示个人参与的所有相关事件
- **统计分析** - 人员参与事件的统计数据和趋势

### 🤖 AI智能问答
- **智能对话** - 基于事件数据的自然语言问答
- **数据洞察** - AI驱动的数据分析和趋势识别
- **决策支持** - 为管理决策提供智能建议
- **知识库** - 基于历史事件数据构建的知识库

### 📊 统计报告系统
- **动态报告** - 实时生成数据统计报告
- **可视化图表** - 多种图表类型展示数据趋势
- **关键指标** - 核心业务指标的监控和分析
- **导出功能** - 支持报告数据的导出和分享

## 技术架构

### 后端技术栈
- **Web框架**：FastAPI - 现代化的Python Web框架
- **数据处理**：Pandas + DuckDB - 高性能数据分析
- **AI服务**：OpenAI + ChromaDB - 智能问答和向量搜索
- **API文档**：Swagger UI - 自动生成的API文档
- **数据库**：SQLite + CSV - 轻量级数据存储

### 前端技术栈
- **框架**：React 18 - 现代化前端框架
- **UI组件库**：Ant Design 5 - 企业级UI设计语言
- **状态管理**：React Context + Hooks - 轻量级状态管理
- **路由管理**：React Router 6 - 声明式路由
- **HTTP客户端**：Axios - Promise based HTTP 库
- **国际化**：Ant Design 中文语言包

### 架构特点
- **前后端分离** - 独立开发部署，提高开发效率
- **响应式设计** - 适配不同屏幕尺寸的设备
- **模块化开发** - 组件化设计，易于维护和扩展
- **API优先** - RESTful API设计，支持多端接入

## 快速开始

```bash

./start.sh --frontend-only
```

## 🔌 API 接口文档

### 🔐 认证相关
- **GET** `/api/health` - 系统健康检查
- **POST** `/api/auth/login` - 用户登录认证

### 📋 事件管理
- **GET** `/api/events` - 获取事件列表（支持搜索筛选分页）
- **GET** `/api/events/{event_id}` - 获取单个事件详情
- **GET** `/api/filter-options` - 获取筛选选项

### 🔗 聚类事件
- **GET** `/api/cluster-list` - 获取聚类事件列表
- **GET** `/api/clusters/{event_uid}` - 获取聚类事件详情和时间线
- **GET** `/api/cluster-filter-options` - 获取聚类筛选选项

### 👥 人员分析
- **POST** `/api/people/search` - 搜索人口信息
- **GET** `/api/people/{person_id}` - 获取人员详细信息
- **GET** `/api/person-analysis` - 获取人员分析列表
- **GET** `/api/person-analysis/{phone}` - 获取人员详细分析

### 🤖 AI 智能问答
- **POST** `/api/chat` - AI聊天对话
- **GET** `/api/chat/health` - AI服务健康检查
- **GET** `/api/chat/statistics` - AI使用统计

### 📊 统计报告
- **GET** `/api/statistics/report` - 获取统计报告数据

所有接口详情请访问：**http://localhost:8000/docs**

## 📊 数据字段说明

### 🆔 核心标识
- **EventUID** - 聚类事件唯一标识符，用于关联相关事件
- **事件编号** - 单个事件的唯一编号
- **CallerPhone** - 报警人电话（已脱敏处理）
- **CallerID** - 报警人身份证号（已脱敏处理）

### 📝 事件信息
- **事件描述** - 事件的详细描述和背景信息
- **处置结果** - 事件的处理结果和解决方案
- **phone_set** - 参与者电话号码集合
- **sequence_total** - 聚类中包含的事件总数

### ⏰ 时间信息
- **上报时间** - 事件首次上报的时间
- **办结时间** - 事件处理完成的时间
- **持续时间** - 聚类事件的整体持续时间

### 🏘️ 地理分类
- **镇街名称** - 事件发生的镇街行政区域
- **村社名称** - 事件发生的村社区域
- **事件级别** - 事件的重要性和紧急程度级别
- **二级分类** - 事件的详细分类类别

### 👤 人员信息
- **参与人数** - 事件涉及的人员数量
- **角色类型** - 人员在事件中的角色（报警人、当事人等）
- **人员画像** - 基于历史数据的人员行为分析
