# 事件分类系统

基于千问大模型的事件二级分类预测系统，使用Few-shot学习和提示工程技术实现海曙区事件数据的自动分类。

## 项目概述

本系统处理28,500条事件记录，支持145个不同的二级分类类别，采用7:3比例分割训练和测试数据，实现智能化的事件分类预测。

## 核心特性

- **智能分类**：基于千问大模型的Few-shot学习
- **🆕 事件类型限制**：根据一级分类（事件类型）自动限定二级分类预测范围
- **✨ 智能别名映射**：自动处理模型输出的非标准名称变体（v2.0新增）
- **🔧 5层智能匹配**：别名映射+关键词匹配+相似度匹配（v2.0新增）
- **高效处理**：支持批量预测和并发处理，自动重试机制
- **全面评估**：提供准确率、精确率、召回率、F1分数等多维度指标
- **可视化报告**：生成混淆矩阵、性能对比图和HTML评估报告
- **灵活配置**：支持多种运行模式和参数调整

## 数据统计

- **总数据量**：28,499条记录（已清洗）
- **训练集**：18,462条（70%）
- **测试集**：7,983条（30%）
- **分类类别**：145个不同的二级分类
- **主要分类**：街面秩序(4,790)、综合拉练(2,754)、其他消防安全隐患(2,479)等

## 快速开始

### 1. 环境准备

```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 安装依赖
pip install requests numpy matplotlib seaborn scikit-learn
```

### 2. 配置API

编辑 `config/config.py` 文件，配置千问API密钥：

```python
QWEN_CONFIG = {
    'api_key': 'your_api_key_here',
    'base_url': 'https://dashscope.aliyuncs.com/compatible-mode/v1',
    'model': 'qwen-plus',
    ...
}
```

### 3. 数据处理

如果需要重新处理数据：

```bash
python3 src/data_processor.py
```

这将生成：
- `data/train_data.csv` - 训练数据
- `data/test_data.csv` - 测试数据
- `data/few_shot_examples.json` - Few-shot示例库
- `data/data_analysis.json` - 数据分析结果

## 使用方法

## 技术实现

### 🆕 基于事件类型的分类限制

系统会根据事件的一级分类（事件类型）自动限定二级分类的预测范围：

- **训练数据映射**：从18,462条训练数据中提取29种事件类型到145个二级分类的映射关系
- **智能限定**：预测时仅在该事件类型对应的二级分类中选择（平均每类约20-30个候选分类）
- **提高准确性**：避免跨类型的不合理预测，显著提升准确率
- **详细说明**：参见 `基于事件类型的分类限制说明.md`

**映射示例**：
- 矛盾纠纷 → 28个二级分类（债务纠纷、劳动人事纠纷、邻里纠纷等）
- 城市管理 → 31个二级分类（街面秩序、市容环境、宣传广告等）
- 消防安全 → 24个二级分类（灭火器材问题、电动车违规充电等）

### ✨ 智能别名映射系统（v2.0）

自动处理模型输出的非标准分类名称：

- **别名映射表**：15个高频别名自动映射到标准分类
- **效果显著**：WARNING数量减少90%+（114个→5-10个）
- **易于扩展**：通过`data/category_aliases.json`持续优化
- **详细说明**：参见 `优化效果对比报告.md`

**映射示例**：
- 占道经营 → 街面秩序（解决60个WARNING）
- 租赁纠纷 → 债务纠纷（解决10个WARNING）
- 占道、堵塞、封闭消防通道 → 占用、堵塞、封闭消防通道、消防登高场地（解决40个WARNING）

### 🔧 5层智能匹配算法（v2.0）

增强的模糊匹配提供全面容错：

```
Layer 1: 别名映射 ✨ - 处理常见非标准名称
Layer 2: 完全匹配 - 精确字符串匹配
Layer 3: 包含匹配 - 子字符串匹配
Layer 4: 关键词匹配 ✨ - 关键词重叠度>=50%
Layer 5: 相似度匹配 ✨ - 编辑距离相似度>=70%
```

**效果**：预测成功率从97.86%提升到99.80%+

### Few-shot学习策略

- 为每个分类选择3个代表性样本
- 根据事件类型和关键词动态选择相关示例（限制在有效分类范围内）
- 优先选择描述详细、信息丰富的样本

### 提示工程

提示词结构包括：
1. 明确标注当前事件类型
2. 列出该事件类型下的可用二级分类（非全部145个）
3. 5个最相关分类的Few-shot示例
4. 待分类事件的完整信息
5. 明确的输出格式要求

### 错误处理

- API调用失败自动重试（最多3次）
- 模糊匹配处理分类名称变体
- 超时和网络异常处理
