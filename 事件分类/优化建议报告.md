## 🎯 二、核心问题诊断

### 问题1：街面秩序 vs 市容环境（超级混淆对）

**严重程度**: ⭐⭐⭐⭐⭐ **占所有错误的23%！**

**数据**:
- 混淆次数: 530次（街面秩序→市容环境）
- 街面秩序: P=84.8%, R=33.8%, F1=0.484 (样本数958)
- 市容环境: P=22.0%, R=98.4%, F1=0.360 (样本数182)

**问题分析**:
1. 市容环境召回率98.4%，但精确率只有22% → 大量误判到市容环境
2. 街面秩序召回率只有33.8% → 大量街面秩序被误判为市容环境
3. 模型倾向于将模糊案例都判为市容环境

**根本原因**:
- 两个分类的关键词重叠度高（都涉及"公共场所"、"影响环境"）
- 当前辨析指南不够精准
- 缺少负面示例（什么**不是**市容环境）

**优化方案** (预期+5-8%):

#### 方案A: 强化对比学习（高优先级）
```python
# 在提示词中增加更强的决策规则
核心决策规则：
1. 如果事件主要问题是【物体占用空间、阻碍通行】→ 街面秩序
   - 关键词: 占道、摊贩、违停、堵塞、跨门经营
   - 判断标准: 影响人/车通行

2. 如果事件主要问题是【环境不洁、需要清理】→ 市容环境
   - 关键词: 垃圾、污物、卫生、清洁、脏乱
   - 判断标准: 影响环境卫生

3. 优先级判断: 占道 > 卫生
   - "垃圾桶占道" → 街面秩序（占道优先）
   - "垃圾桶旁有垃圾" → 市容环境（卫生问题）
```

#### 方案B: 增加负面Few-shot示例
为市容环境添加"反面案例"：
```
❌ 不是市容环境的案例：
- "流动摊贩占道经营" → 街面秩序（虽然影响环境，但核心是占道）
- "车辆违规停放人行道" → 街面秩序（虽然影响市容，但核心是违停）
- "楼道堆放杂物" → 如涉及消防通道则为消防类
```

#### 方案C: 提升市容环境的判断阈值
```python
# 在_build_prompt()中添加特殊规则
if '市容环境' in valid_categories:
    prompt += "\n⚠️ 市容环境判断的严格标准：\n"
    prompt += "只有当事件的**核心问题**是垃圾、污物、环境脏乱时，才选择市容环境\n"
    prompt += "如果事件同时涉及占道和卫生问题，优先选择街面秩序\n\n"
```

- 行业拉练: P=0.6%, R=? (精确率极低)

- 168次错误全部是 综合拉练 被误判为 行业拉练
- 行业拉练精确率只有0.6%，说明基本都是误判
- 当前辨析指南不够具体

**优化方案** (预期+2-3%):

#### 增强拉练分类的决策树
```python
拉练分类决策树：
1. 如果包含【小候鸟、走访正常、走访对象】→ 100% 综合拉练
2. 如果包含【电动车检查、专项检查、联合排查】→ 行业拉练
3. 如果只说"巡查"、"检查"，无明确对象 → 默认综合拉练
4. 如果同时涉及多个领域检查 → 综合拉练
```

### 🎯 中期优化（预期收益+6-10%）

#### 5. 实施两阶段分类

**第一阶段**：粗分类（8-10大类）
```
1. 城市管理类（街面秩序、市容环境、公用设施等）
2. 消防安全类（各类消防隐患）
3. 纠纷调解类（各类纠纷）
4. 综合巡查类（综合拉练、行业拉练等）
...
```

**第二阶段**：细分类
- 在每个大类内部再进行细分
- 减少候选数量，提高准确率

**实施方式**：
```python
def classify_two_stage(self, event_data):
    # 第一阶段：粗分类
    broad_category = self._classify_broad(event_data)

    # 第二阶段：在该大类下细分
    valid_categories = self.broad_to_fine[broad_category]
    fine_category = self._classify_fine(event_data, valid_categories)

    return fine_category
```

#### 7. 引入置信度阈值机制

```python
def classify_with_confidence_threshold(self, event_data, threshold=0.7):
    result, confidence = self.classify_single(event_data)

    if confidence < threshold:
        # 低置信度：返回top-3候选供人工选择
        return {
            'category': result,
            'confidence': confidence,
            'status': 'NEEDS_REVIEW',
            'candidates': self._get_top_k_candidates(event_data, k=3)
        }
    else:
        return {
            'category': result,
            'confidence': confidence,
            'status': 'CONFIRMED'
        }
```
