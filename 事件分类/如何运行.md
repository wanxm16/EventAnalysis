## 🔧 环境配置

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：
- `openai` - 用于调用千问大模型API
- `pandas` - 数据处理
- `scikit-learn` - 评估指标计算
- `matplotlib`, `seaborn` - 可视化
- `python-dotenv` - 环境变量管理

### 2. 配置API密钥

创建 `.env` 文件（或编辑现有文件）：

```bash
QWEN_API_KEY=your_api_key_here
```

**获取API密钥：**
- 访问阿里云百炼平台：https://bailian.console.aliyun.com/
- 申请千问模型API密钥
- 将密钥填入 `.env` 文件

## 📖 运行命令详解

### 1. 数据预处理（首次运行或数据更新时）

```bash
python src/data_processor.py
```

**功能：**
- 加载原始数据文件
- 生成事件类型映射关系
- 生成Few-shot示例（每个分类5个代表性样本）
- 输出文件保存在 `data/` 目录

**输出文件：**
- `data/event_type_mapping.json` - 一级事件类型与二级分类的映射
- `data/category_aliases.json` - 分类别名映射
- `data/few_shot_examples.json` - Few-shot示例库

### 2. 运行分类测试

#### 快速测试（100样本）

```bash
python src/qwen_classifier.py --quick-test
```

**特点：**
- 测试时间：约10秒
- 样本数量：100个
- 适用场景：快速验证、调试、演示

#### 完整测试（全量）

```bash
python src/qwen_classifier.py
```

**特点：**
- 测试时间：约15-20分钟
- 样本数量：5,335个
- 适用场景：完整性能评估、最终验证

### 3. 自定义测试样本数量

```bash
python src/qwen_classifier.py --sample-size 500
```

可以指定任意测试样本数量（1-5335）

```
results/
├── quick_test_predictions.csv      # 预测结果CSV（快速测试）
```

### 查看评估报告

**方式一：在浏览器中打开HTML报告**

```bash
open results/evaluation_report.html
```

（Mac系统，Windows使用 `start`，Linux使用 `xdg-open`）

**方式二：查看图表**

- `category_performance.png` - 显示各分类的精确率、召回率、F1分数
- `confusion_matrix.png` - 显示分类混淆情况

### 关键指标解读

| 指标 | 说明 | 当前值 |
|------|------|--------|
| **准确率 (Accuracy)** | 整体预测正确的比例 | 49.0% |
| **宏平均F1** | 不考虑样本分布的平均F1 | 0.284 |
| **加权平均F1** | 考虑样本分布的平均F1 | 0.494 |
| **预测成功率** | API调用成功率 | 100% |
| **平均置信度** | 模型预测的平均置信度 | 0.894 |

### 性能分类标准

报告中使用颜色标记各分类的F1分数：

- 🟢 **绿色 (F1 ≥ 0.7)** - 性能良好
- 🟡 **黄色 (0.5 ≤ F1 < 0.7)** - 性能中等
- 🔴 **红色 (F1 < 0.5)** - 性能较差，需要优化

## 🔍 常见问题

### Q1: 运行时提示 "API密钥未配置"

**解决方法：**
```bash
# 检查.env文件是否存在
cat .env

# 如果不存在，创建并添加密钥
echo "QWEN_API_KEY=your_actual_key" > .env
```

### Q2: 测试速度很慢

**原因：** 使用了完整测试（5335个样本）

**解决方法：**
```bash
# 使用快速测试
python src/qwen_classifier.py --quick-test

# 或指定较小样本数
python src/qwen_classifier.py --sample-size 200
```

### Q3: 如何提高分类准确率？

当前系统已实现的优化：
- ✅ 动态Few-shot示例选择（基于相似度）
- ✅ 多样性采样（MMR算法）
- ✅ 事件类型限制（减少候选分类）

可进一步优化的方向：
1. 增加混淆分类的区分示例
2. 优化相似度计算的权重
3. 对低频分类进行数据增强
4. 尝试使用更大的模型（如qwen-max）

### Q4: 如何单独测试某个事件？

```python
# 创建测试脚本 test_single.py
from src.qwen_classifier import QwenClassifier

classifier = QwenClassifier()
classifier.connect()

result = classifier.classify_event(
    event_description="小区楼道内有电动车充电",
    event_type="消防安全"
)

print(f"分类结果: {result['category']}")
print(f"置信度: {result['confidence']}")
```

### Q5: 预测结果CSV在哪里？

- 快速测试：`results/quick_test_predictions.csv`
- 完整测试：`results/predictions.csv`

可以使用Excel或pandas查看：
```python
import pandas as pd
df = pd.read_csv('results/quick_test_predictions.csv')
print(df.head())
```

## 🛠 技术参数

### API配置
- **模型**: qwen-plus
- **并发线程数**: 20
- **超时时间**: 30秒/请求
- **温度**: 0.1（低温度保证稳定性）

### Few-shot配置
- **每分类示例数**: 5个
- **提示词中使用数**: 动态选择最相似的5个
- **相似度权重**:
  - 关键词相似度: 50%
  - 事件类型匹配: 30%
  - 长度相似度: 10%
  - 特殊词匹配: 10%
