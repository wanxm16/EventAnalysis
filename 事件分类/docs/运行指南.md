
   ```python

   ```

## 常见问题

### Q1：运行到一半中断了怎么办？

A：重新运行时会自动跳过已有的预测结果（如果使用了 `--skip-existing`）

### Q2：预测结果不理想怎么办？

A：
1. 检查 `results/evaluation_report.html` 找出表现差的分类
2. 查看 `data/few_shot_examples.json` 优化示例质量
3. 调整配置参数重新测试

### Q3：API调用频繁失败？

A：
1. 检查网络连接
2. 验证API密钥有效性
3. 增加重试延迟时间：
   ```python
   'retry_delay': 2  # 从1秒增加到2秒
   ```

### Q4：如何只测试特定分类？

A：修改 `src/main.py`，添加分类过滤逻辑
