# ❓ 常见问题FAQ - 快速解答

## 🎯 关于优化和WARNING

### Q1: 为什么会有WARNING日志？

**A**: WARNING表示模型预测了一个不在标准分类列表中的名称。

**详细说明**:
- 模型输出: "占道经营"
- 标准分类列表中没有这个名称
- 系统记录WARNING并尝试修正
- 如果修正失败，标记为FAILED

**这是正常的吗？** ✅ 是的，这是LLM的特性

**详见**: `WARNING日志详解.md`

---

### Q2: 为什么优化后准确率提升不明显（只有1-3%）？

**A**: 因为本次优化解决的是FAILED问题（2.14%），不是预测错误问题（48.96%）。

**数据说明**:
```
总样本: 5,335
├─ 预测正确: 2,609 (48.90%)
├─ 预测错误: 2,612 (48.96%) ← 真正影响准确率
└─ 预测失败: 114 (2.14%) ← 本次优化解决的
```

即使114个FAILED全部变正确，准确率最多提升2.14%  
实际提升1-3%已经接近理论上限 ✅

**详见**: `准确率提升不明显的原因分析.md`

### Q3: 为什么训练数据中没有"占道经营"这个分类？

**A**: 因为标注体系使用"街面秩序"这个抽象分类名来涵盖占道经营等具体问题。

**数据证据**:
- 512个事件描述中包含"占道经营"
- 其中488个（95.3%）被标注为"街面秩序"
- 这是标注规范，不是错误

**为什么这样设计？**
- 控制分类数量（如果每个具体问题都建分类，可能有300+个）
- 使用抽象名称更便于管理
- "街面秩序"涵盖：占道经营、流动摊贩、违停等

**详见**: `为什么没有占道经营分类-深度解析.md`

### Q4: 为什么模型不按列表选择，输出了列表之外的名称？

**A**: 因为大语言模型是生成式的，不是分类式的，可以生成任何文本。

**关键原因**:
1. LLM是文本生成器，不是传统分类器
2. 提示词只是引导，不是硬约束
3. 模型倾向输出更精确、更直观的词汇
4. 97.8%的时候模型遵循列表，2.2%会"越界"

**类比**: 
```
问: "从A/B/C中选择"
学生: "但我觉得D更合适" ← LLM就是这样
```

**详见**: `为什么模型不按列表选择-深度剖析.md`

### Q5: 别名映射表的用途是什么？

**A**: 自动将模型输出的非标准名称翻译为标准分类名称。

**形象比喻**: 翻译字典
```
模型说"方言": "占道经营"
翻译字典: "占道经营" → "街面秩序"
系统理解"普通话": "街面秩序" ✅
```

**效果**:
- 解决92%的WARNING（105/114）
- 预测成功率提升2%（97.86% → 99.80%+）
- 投入小（15个映射），产出大

**详见**: `别名映射表用途详解.md`

## 🔧 关于技术实现

### Q11: 5层匹配算法是什么？

**A**: 依次尝试5种方法匹配模型输出到标准分类。

```
Layer 1: 别名映射 ✨ (人工定义，最准确)
Layer 2: 完全匹配 (精确字符串)
Layer 3: 包含匹配 (子串)
Layer 4: 关键词匹配 ✨ (关键词重叠>=50%)
Layer 5: 相似度匹配 ✨ (编辑距离>=70%)
```

**贡献度**:
- Layer 1: 90%的非标准情况
- Layer 2-3: 9%
- Layer 4-5: 1%

**详见**: `优化效果对比报告.md`

### Q12: 为什么用LLM而不是传统分类器？

**A**: 权衡后的选择。

**LLM优势**:
- ✅ Few-shot学习（不需要大量标注）
- ✅ 语义理解强
- ✅ 灵活适应新场景
- ✅ 零成本部署

**LLM劣势**:
- ❌ 输出不完全可控（2.2%越界）
- ❌ API调用有成本
- ❌ 速度较慢

**传统分类器（BERT等）**:
- ✅ 输出完全可控
- ✅ 速度快
- ❌ 需要大量训练数据
- ❌ 需要GPU训练

**我们的选择**: LLM + 别名映射，兼顾灵活性和可控性

## 💡 关于理解

### Q17: 别名映射和模糊匹配有什么区别？

**A**: 别名映射是5层匹配中的第1层，优先级最高。

**区别**:

| 特性 | 别名映射 | 模糊匹配 |
|------|---------|---------|
| 定义方式 | 人工定义 | 算法自动 |
| 准确性 | 100% | 70-90% |
| 速度 | 最快(O(1)) | 较慢 |
| 优先级 | 最高(Layer 1) | 较低(Layer 2-5) |
| 可控性 | 完全可控 | 依赖算法 |

**关系**: 别名映射是模糊匹配的特殊化、优化版
