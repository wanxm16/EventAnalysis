## 📁 新增文件

### 1. 分类别名映射表

**路径**: `data/category_aliases.json`

**作用**: 将模型输出的非标准名称自动映射到标准分类

**示例**:
```json
{
  "占道经营": "街面秩序",
  "租赁纠纷": "债务纠纷",
  "占道、堵塞、封闭消防通道": "占用、堵塞、封闭消防通道、消防登高场地"
}
```

**如何扩展**:

如果发现新的WARNING，可以手动添加映射：

```json
{
  "新的变体名称": "标准分类名称"
}
```

## 🔧 核心改进说明

### 改进1: 智能别名映射

**位置**: `src/qwen_classifier.py` - `_fuzzy_match()` 方法

**工作原理**:
```python
# 模型输出: "占道经营"
# 系统检查: 这个在别名表吗？
# 找到映射: "占道经营" → "街面秩序"
# 验证: "街面秩序" 在有效分类中吗？✅
# 返回: "街面秩序" (置信度0.7)
```

**优势**:
- ⚡ 快速: 优先级最高，首先检查
- 🎯 准确: 人工定义的映射关系
- 🔄 可扩展: 随时添加新的映射

### 改进2: 关键词匹配

**原理**: 将分类名称拆分为关键词，计算重叠度

**示例**:
```python
预测: "占道、堵塞、消防通道"
标准: "占用、堵塞、封闭消防通道、消防登高场地"

关键词重叠: ["堵塞", "消防通道"] / 总关键词
相似度: 50%+ → 匹配成功
```

### 改进3: 编辑距离匹配

**原理**: 计算字符串相似度

**示例**:
```python
预测: "占道经营-流动摊"
最相似: "街面秩序" (相似度可能不够)

相似度: 30% → 未匹配（需要>=70%）
```

## ⚙️ 配置参数

### 匹配阈值（可调整）

在 `_fuzzy_match()` 方法中：

```python
# 关键词匹配阈值
if best_score >= 0.5:  # 默认50%，可调整为0.3-0.7
    return best_match

# 相似度匹配阈值  
if best_ratio >= 0.7:  # 默认70%，可调整为0.6-0.8
    return best_match
```

**调整建议**:
- 降低阈值 → 更多匹配，但可能误匹配
- 提高阈值 → 更严格，但可能漏掉合理匹配

## ❓ 常见问题

### Q1: 为什么还有WARNING？

**A**: 可能是别名表未覆盖的新变体。解决方法：
1. 查看WARNING中的分类名称
2. 判断应该映射到哪个标准分类
3. 添加到 `data/category_aliases.json`

### Q2: 别名映射会降低置信度吗？

**A**: 会的。别名匹配的置信度是0.7（vs精确匹配的0.9），这是合理的：
- 精确匹配: 模型输出完全正确 → 0.9
- 别名映射: 系统自动纠正 → 0.7
- 这样可以在评估时区分这两种情况

### Q3: 如何知道用了哪一层匹配？

**A**: 启用DEBUG日志级别，会显示详细匹配过程

### Q4: 别名映射会影响准确率吗？

**A**: 正面影响。之前FAILED的样本现在可能被正确映射，增加准确样本数。
