# 并发模式使用说明

## 🚀 并发模式优势

使用并发模式可以显著提高处理速度：
- **串行模式**：每次处理1个样本，7,983个样本约需 6-8小时
- **并发模式**：同时处理20个样本，7,983个样本约需 20-40分钟

**速度提升：约10-20倍！**

## 📋 使用方法

### 方式1：使用默认配置（推荐）

配置文件已默认启用并发模式：

```bash
source venv/bin/activate
python3 src/main.py --mode full
```

### 方式2：命令行指定参数

```bash
# 启用并发，使用20个线程
python3 src/main.py --mode full --concurrent --workers 20

# 启用并发，自动确定线程数
python3 src/main.py --mode full --concurrent

# 禁用并发，使用串行模式
python3 src/main.py --mode full --no-concurrent
```

### 方式3：修改配置文件

编辑 `config/config.py`：

```python
CLASSIFICATION_CONFIG = {
    'use_concurrent': True,   # True启用并发，False使用串行
    'max_workers': 20,        # 并发线程数，None表示自动（最多20）
}
```

## ⚙️ 参数说明

### --concurrent / --no-concurrent
- `--concurrent`: 启用并发模式
- `--no-concurrent`: 禁用并发，使用串行模式
- 不指定：使用配置文件设置（默认启用）

### --workers N
- 设置并发线程数
- 推荐值：10-20
- 过大可能导致API限流
- 不指定：使用配置文件设置或自动（最多20）

## 🔧 调优建议

### 线程数选择

1. **保守策略**（稳定优先）
   ```bash
   --workers 10
   ```
   - 适合：网络不稳定、API有限流
   - 速度：中等
   - 稳定性：高

2. **平衡策略**（推荐）
   ```bash
   --workers 20
   ```
   - 适合：大多数场景
   - 速度：快
   - 稳定性：好

3. **激进策略**（速度优先）
   ```bash
   --workers 30
   ```
   - 适合：网络稳定、无API限流
   - 速度：最快
   - 稳定性：可能遇到限流

### 网络环境调整

**网络良好**：
```python
'max_workers': 30,
'timeout': 20,
'max_retries': 2,
```

**网络一般**：
```python
'max_workers': 20,
'timeout': 30,
'max_retries': 3,
```

**网络较差**：
```python
'max_workers': 10,
'timeout': 60,
'max_retries': 5,
```

## ⚠️ 注意事项

### 1. API限流
千问API可能有调用频率限制，如遇到大量失败：
- 减少线程数：`--workers 10`
- 增加重试次数：修改 `config.py` 中的 `max_retries`
- 增加超时时间：修改 `config.py` 中的 `timeout`

### 2. 内存占用
并发模式会增加内存占用：
- 10线程：~500MB
- 20线程：~600MB
- 30线程：~800MB

内存不足时减少线程数。

### 3. 网络稳定性
并发模式对网络要求较高，如经常超时：
- 使用串行模式：`--no-concurrent`
- 减少线程数：`--workers 5`
- 增加超时时间

### 4. 进度显示
并发模式下，进度每完成50个样本显示一次：
```
进度: 50/7983 (0.6%)
进度: 100/7983 (1.3%)
...
```

## 🐛 故障排查

### 问题1：大量API调用失败
**现象**：出现很多"API请求失败"错误

**解决**：
```bash
# 减少并发数
python3 src/main.py --mode full --workers 10

# 或使用串行模式
python3 src/main.py --mode full --no-concurrent
```

### 问题2：内存不足
**现象**：系统变慢或程序崩溃

**解决**：
```bash
# 减少线程数
python3 src/main.py --mode full --workers 10
```

### 问题3：网络超时
**现象**：频繁出现超时错误

**解决**：
修改 `config/config.py`：
```python
QWEN_CONFIG = {
    'timeout': 60,      # 增加到60秒
    'max_retries': 5,   # 增加重试次数
}
```

### 问题4：进程卡住
**现象**：长时间无进度更新

**解决**：
1. 检查网络连接
2. 查看日志文件
3. 使用 Ctrl+C 中断，减少线程数后重试
