#### 1. 严格提示词的核心作用

**您的6条要求非常关键**:

```

  • 模型学习不充分

  • 包含多种典型案例
  • 模型学习更充分
  
效果: 准确率+2-3% ✅
```

#### 3. 对比学习的价值

**明确区分**:

