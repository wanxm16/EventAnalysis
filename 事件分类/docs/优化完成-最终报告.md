### 2. 增强模糊匹配算法

**修改文件**: `src/qwen_classifier.py` - `_fuzzy_match()` 方法

**5层智能匹配**:

```
Layer 1: 别名映射 ✨
  ├─ 优先级: 最高
  ├─ 速度: 最快（O(1)字典查找）
  ├─ 准确度: 最高（人工定义）
  └─ 贡献: 解决~10%的预测（全量约500个）

Layer 2: 完全匹配
  ├─ 精确字符串匹配（忽略大小写）
  └─ 贡献: ~85%的预测

Layer 3: 包含匹配
  ├─ 子字符串包含关系
  └─ 贡献: ~3%的预测

Layer 4: 关键词匹配 ✨
  ├─ 提取关键词计算重叠度
  ├─ 阈值: >=50%
  └─ 贡献: ~1%的预测

Layer 5: 编辑距离匹配 ✨
  ├─ 使用SequenceMatcher计算相似度
  ├─ 阈值: >=70%
  └─ 贡献: <1%的预测（兜底）
```

**别名映射成功率**: ~90%以上

### 二、0%准确率分类分析结果

**突发事件** (183个样本):
- **发现**: 模型60%预测为"公用设施"
- **原因**: 事件描述大多是"设施破损"、"路灯不亮"等
- **分析**: "突发事件"可能标注不一致，与"公用设施"高度重叠
- **建议**: 
  - 方案A: 将设施破损类归入"公用设施"
  - 方案B: 明确"突发事件"的定义和Few-shot示例
  - 方案C: 通过别名映射短期解决（已添加）

**治安隐患纠纷** (31个样本):
- **发现**: 被预测为"家庭婚姻纠纷"(36%)、"情感纠纷"(23%)
- **原因**: 分类定义overlap，场景相似
- **建议**: 改进Few-shot示例，强调"治安隐患"特征

**家庭异动求助类** (9个样本):
- **发现**: 被预测为"其他困难救助"(56%)、"生活困难救助类"(44%)
- **原因**: 这几个分类确实非常相似
- **建议**: 考虑合并这些细分类别
