# UC02-人工审核匹配

### 1. 用户故事
As a 属地管理员, I want to review并确认系统低置信度或多候选的镇街/社区匹配结果, So that 我能够确保属地数据的准确性与可追溯性。

### 3. 验收标准
- 自动匹配产生的低置信度事件应进入可过滤与排序的审核列表, 展示原始地址及候选镇街/社区与各自置信度。
- 审核员可在界面中选择正确的属地信息或手动输入新值, 并填写处理备注。
- 审核确认后系统需同步更新事件记录, 标记处理人、处理时间及最终决策来源。
- 审核操作应支持并发≤10名用户同时处理, 且保证数据一致性不冲突。
- 审核结果应回写至自动匹配模型或词库, 用于后续智能匹配优化。

### 4. 风险评估
- 审核流程过多导致处理效率低 → 提供批量确认与快捷操作功能。
- 人工输入可能产生新错误 → 增加格式校验与历史建议。
- 并发审核时数据覆盖 → 实施悲观/乐观锁策略与版本控制。
