# AI智能配置主题功能需求文档

## 1. 项目概述

### 1.1 项目背景
现有的事件管理系统中，主题创建主要依赖人工配置规则，需要用户手动设置包含关键词、排除关键词、精细筛选等条件。这种方式对用户的专业性要求较高，配置复杂，效率低下。为了降低使用门槛，提升用户体验，需要引入AI智能配置功能，让用户通过自然语言描述和示例就能快速创建准确的主题分类规则。

### 1.2 产品目标
- 降低主题创建的技术门槛，让普通用户也能快速创建有效的主题
- 通过AI理解用户意图，自动生成准确的分类规则
- 提供直观的few-shot学习界面，让用户通过示例来指导AI生成规则
- 保持与传统规则配置的兼容性，用户可以在AI生成基础上进一步调整
- 提升主题创建的效率和准确性

### 1.3 目标用户
- **业务人员**：了解业务场景但缺乏技术背景，希望快速创建主题分类
- **系统管理员**：需要批量创建多个主题，希望提升配置效率
- **新手用户**：不熟悉规则配置语法，需要智能化辅助

## 2. 需求分析

### 2.1 功能需求

#### 2.1.1 智能主题生成
- **自然语言描述**：用户用自然语言描述想要创建的主题类型
- **Few-shot示例学习**：用户提供正例和反例，AI据此理解分类意图
- **预设模板系统**：提供常见场景的预设模板，如噪音投诉、停车问题等
- **规则自动生成**：AI分析描述和示例，自动生成包含/排除关键词
- **生成过程解释**：展示AI的推理过程，让用户理解生成逻辑

#### 2.1.2 交互界面设计
- **模式切换**：支持"AI智能创建"和"手动规则配置"两种模式
- **模板选择器**：快速选择预设模板作为起点
- **示例输入区**：支持输入多组正例和反例
- **实时预览**：输入过程中实时显示生成的规则
- **结果编辑**：AI生成结果可进一步手动调整

#### 2.1.3 AI处理能力
- **关键词提取**：从描述和示例中提取核心关键词
- **语义理解**：理解用户描述的业务场景和分类意图
- **规则推理**：基于示例推断包含/排除规则
- **置信度评估**：对生成规则的准确性进行评估
- **多轮优化**：支持用户反馈后重新生成

### 2.2 非功能需求

#### 2.2.1 性能要求
- AI生成响应时间不超过5秒
- 支持并发处理多个生成请求
- 模板加载和预览响应及时

#### 2.2.2 准确性要求
- AI生成规则的准确率不低于80%
- 提供规则解释和置信度指标
- 支持用户验证和调整机制

#### 2.2.3 易用性要求
- 界面操作流程简洁直观
- 提供详细的使用指导和示例
- 错误提示清晰明确

### 3.3 AI生成流程

#### 3.3.1 输入处理
1. **描述分析**：对用户输入的场景描述进行分词和语义分析
2. **示例解析**：提取正例和反例中的关键信息
3. **模板匹配**：如果选择了预设模板，融合模板信息
4. **特征提取**：识别描述性词汇、业务术语、情感词等

#### 3.3.2 规则生成
1. **关键词抽取**：从正例中提取高频关键词作为包含条件
2. **排除词识别**：从反例中识别需要排除的关键词
3. **语义扩展**：基于同义词库扩展相关词汇
4. **权重计算**：为不同关键词分配权重和优先级
5. **规则组合**：生成最终的包含/排除规则组合

#### 3.3.3 结果验证
1. **内部验证**：用提供的示例验证生成规则的准确性
2. **置信度计算**：基于匹配程度计算规则置信度
3. **异常检测**：识别可能的规则冲突或遗漏
4. **建议生成**：为低置信度规则提供改进建议

### 4.3 核心算法实现

#### 4.3.1 关键词提取算法
```python
def extract_keywords(texts, max_keywords=10):
    """
    从文本列表中提取关键词
    """
    # 文本预处理
    processed_texts = [preprocess_text(text) for text in texts]

    # TF-IDF特征提取
    vectorizer = TfidfVectorizer(
        max_features=1000,
        stop_words=get_chinese_stopwords(),
        ngram_range=(1, 2)
    )

    tfidf_matrix = vectorizer.fit_transform(processed_texts)
    feature_names = vectorizer.get_feature_names_out()

    # 计算平均TF-IDF分数
    mean_scores = tfidf_matrix.mean(axis=0).A1

    # 选择top-k关键词
    top_indices = mean_scores.argsort()[-max_keywords:][::-1]
    keywords = [feature_names[i] for i in top_indices]

    return keywords
```

#### 4.3.2 规则生成算法
```python
def generate_rules(description, positive_examples, negative_examples):
    """
    基于描述和示例生成分类规则
    """
    # 提取包含关键词（来自正例）
    include_keywords = extract_keywords(
        positive_examples + [description],
        max_keywords=8
    )

    # 提取排除关键词（来自反例）
    exclude_keywords = extract_keywords(
        negative_examples,
        max_keywords=5
    )

    # 去除冲突关键词
    include_keywords = [kw for kw in include_keywords
                       if kw not in exclude_keywords]

    # 语义扩展
    expanded_include = expand_keywords(include_keywords)
    expanded_exclude = expand_keywords(exclude_keywords)

    # 计算置信度
    confidence = calculate_confidence(
        include_keywords, exclude_keywords,
        positive_examples, negative_examples
    )

    return {
        'include_keywords': expanded_include,
        'exclude_keywords': expanded_exclude,
        'confidence': confidence
    }
```
