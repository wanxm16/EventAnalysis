# 需求确认文档

### 1. 最终用户故事清单
#### 核心用户故事
- As a 物业纠纷分析专员, I want the system to利用LLM在10秒内完成事件类型识别并输出解释说明, So that 我能快速获取分类结果并理解判定依据。
- As a 业务审核人员, I want to在模型无法高置信度判断时进行人工确认与纠正, So that 分类结果在入库前保持准确并形成反馈闭环。
- As a 分类标准维护人员, I want to配置、更新并发布纠纷类别及分类规则, So that 系统可持续按最新标准运行并支撑多类分析需求。

### 2. 功能需求矩阵
| 用户故事 | 优先级 | 实现复杂度 | 备注 |
| --- | --- | --- | --- |
| LLM自动分类与解释输出 | 高 | 高 | 响应时长≤10秒, 准确率依赖模型调优, 支持“其他”兜底 |
| 人工确认与反馈闭环 | 高 | 中 | 低置信度需人工确认, 支持修正记录与模型反馈 |
| 分类标准配置管理 | 中 | 中 | 需提供界面管理类别、规则版本与启停控制 |
