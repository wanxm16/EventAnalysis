## 2. 系统概述

### 2.1 业务背景
智研通事件分析系统是一个面向企业级用户的数据分析平台,需要对不同角色的用户进行精细化的权限控制,确保数据安全和业务操作的规范性。系统采用基于角色的访问控制(RBAC)模型,通过用户-角色-权限的三层架构实现灵活的权限管理。

### 2.2 核心概念

#### 2.2.1 RBAC模型
系统采用基于角色的访问控制(Role-Based Access Control, RBAC)模型:
- **用户(User)**: 系统的使用者,可以被分配一个或多个角色
- **角色(Role)**: 权限的集合,代表一类用户的职能
- **权限(Permission)**: 对系统资源的操作许可,包括模块访问权限和具体操作权限

#### 2.2.2 权限层级
- **模块权限**: 对功能模块的访问权限(如:dashboard、events、system等)
- **操作权限**: 对具体操作的执行权限(如:view、create、edit、delete、export等)
- **权限标识格式**: `模块:操作`,例如 `events:view`、`system:users`

### 2.3 系统架构
```
用户(User) ──[N:M]─→ 角色(Role) ──[N:M]─→ 权限(Permission)
```
- 一个用户可以拥有多个角色
- 一个角色可以被分配给多个用户
- 一个角色包含多个权限
- 一个权限可以属于多个角色

## 3. 功能模块详细需求

## 3.1 用户管理

### 3.1.1 功能概述
用户管理模块负责系统用户的全生命周期管理,包括用户的创建、编辑、删除、状态管理、角色分配和权限查看等功能。

### 3.1.2 功能列表

#### 3.1.2.1 用户列表查看
**功能描述**: 以表格形式展示系统所有用户信息

**展示字段**:
| 字段名称 | 字段说明 | 数据类型 | 是否必填 | 备注 |
|---------|---------|---------|---------|------|
| ID | 用户唯一标识 | Integer | 是 | 自增主键 |
| 用户名 | 登录账号 | String | 是 | 唯一,3-20位,只能包含字母、数字、下划线 |
| 姓名 | 真实姓名 | String | 是 | 用于显示 |
| 邮箱 | 电子邮箱 | String | 是 | 唯一,用于通知和密码找回 |
| 手机号 | 联系电话 | String | 是 | 11位中国大陆手机号 |
| 角色 | 用户角色列表 | Array | 是 | 至少选择一个角色 |
| 状态 | 账号状态 | Boolean | 是 | 启用/禁用 |
| 创建时间 | 账号创建时间 | DateTime | 是 | 自动生成 |
| 最后登录 | 最近登录时间 | DateTime | 否 | 用户登录时更新 |

**业务规则**:
1. 默认按创建时间倒序排列
2. 支持分页展示,默认每页10条
3. 支持切换每页显示条数(10/20/50/100)
4. 展示当前页数和总记录数
5. 角色以不同颜色的标签展示(管理员:红色,分析员:蓝色,普通用户:绿色,只读:灰色)
6. 禁用状态的用户应有视觉区分

#### 3.1.2.2 用户搜索
**功能描述**: 通过关键词快速查找用户

**搜索范围**:
- 用户名
- 姓名
- 邮箱

**搜索规则**:
1. 支持模糊匹配,不区分大小写
2. 实时搜索,输入即过滤
3. 支持清空搜索条件
4. 无匹配结果时显示空状态提示

#### 3.1.2.3 添加用户
**功能描述**: 创建新的系统用户账号

**操作流程**:
1. 点击"添加用户"按钮
2. 弹出用户信息表单对话框
3. 填写必填和可选信息
4. 提交表单,系统验证数据
5. 验证通过后创建用户,失败则提示错误信息

**表单字段**:
| 字段名称 | 是否必填 | 验证规则 | 默认值 | 说明 |
|---------|---------|---------|--------|------|
| 用户名 | 是 | 3-20位字母数字下划线,不能重复 | - | 创建后不可修改 |
| 姓名 | 是 | 非空字符串 | - | - |
| 邮箱 | 是 | 符合邮箱格式,不能重复 | - | - |
| 手机号 | 是 | 11位中国大陆手机号 | - | - |
| 密码 | 是 | 至少6位 | - | 需要二次确认 |
| 确认密码 | 是 | 与密码一致 | - | - |
| 角色 | 是 | 至少选择一个 | - | 支持多选 |
| 状态 | 否 | 布尔值 | 启用 | - |

**业务规则**:
1. 用户名创建后不可修改
2. 密码必须二次确认且一致
3. 邮箱和用户名必须全局唯一
4. 新用户默认状态为"启用"
5. 创建成功后可选择是否发送欢迎邮件

**错误提示**:
- 用户名已存在
- 邮箱已被使用
- 手机号格式不正确
- 密码两次输入不一致
- 必填字段未填写

#### 3.1.2.4 编辑用户
**功能描述**: 修改已存在用户的信息

**可编辑字段**:
- 姓名
- 邮箱(需验证唯一性)
- 手机号
- 角色
- 状态

**不可编辑字段**:
- 用户名
- 密码(通过"重置密码"功能单独处理)
- 创建时间
- 最后登录时间

**业务规则**:
1. 编辑时预填充当前用户信息
2. 修改邮箱时需验证新邮箱未被使用
3. 修改角色立即生效,用户需重新登录
4. 保存前需进行表单验证

#### 3.1.2.5 删除用户
**功能描述**: 从系统中删除用户账号

**操作流程**:
1. 点击用户行的"删除"按钮
2. 弹出二次确认对话框
3. 确认后执行删除操作
4. 删除成功后刷新列表并提示

**业务规则**:
1. 删除前必须二次确认
2. 系统管理员账号(admin)不允许删除
3. 删除操作不可恢复
4. 建议采用软删除(逻辑删除)而非物理删除
5. 删除用户时应记录操作日志

**安全限制**:
- 用户不能删除自己
- 至少保留一个系统管理员账号

#### 3.1.2.6 用户状态管理
**功能描述**: 启用或禁用用户账号

**状态说明**:
- **启用**: 用户可以正常登录和使用系统
- **禁用**: 用户无法登录,已登录的会话将失效

**操作方式**:
- 列表中直接切换开关
- 实时生效
- 显示操作结果提示

**业务规则**:
1. 禁用用户立即生效,该用户的所有会话将被终止
2. 启用用户后,用户可以立即登录
3. 系统管理员账号不允许被禁用(至少保留一个)
4. 用户不能禁用自己

#### 3.1.2.7 重置密码
**功能描述**: 管理员为用户重置登录密码

**操作流程**:
1. 点击用户的"重置密码"按钮
2. 弹出确认对话框
3. 确认后系统生成新密码
4. 新密码发送至用户邮箱
5. 提示重置成功

**业务规则**:
1. 系统自动生成8-16位随机密码(包含大小写字母、数字、特殊字符)
2. 新密码通过邮件发送给用户
3. 用户首次使用新密码登录后应强制修改密码
4. 重置操作记录到系统日志
5. 邮件发送失败时应有明确提示

#### 3.1.2.8 用户详情查看
**功能描述**: 查看用户的详细信息和权限明细

**展示内容**:

**基本信息**:
- 用户头像(默认头像)
- 用户ID
- 用户名
- 姓名
- 邮箱
- 手机号
- 账号状态
- 创建时间
- 最后登录时间

**角色信息**:
- 已分配的角色列表
- 角色颜色标签展示

**权限信息**:
- 按模块分组展示用户拥有的所有权限
- 显示权限来源(从哪个角色获得)
- 展示权限标识、名称和描述
- 统计权限总数

**展示形式**:
- 右侧抽屉形式
- 宽度800px
- 支持滚动
- 可折叠展开各个模块

## 3.2 角色管理

### 3.2.1 功能概述
角色管理模块负责系统角色的定义和维护,包括角色的创建、编辑、删除、权限配置等功能。

### 3.2.2 预定义角色

系统预置以下四个标准角色:

#### 系统管理员(admin)
- **描述**: 拥有系统所有权限
- **权限范围**: 全部9个模块的所有操作权限
- **适用人员**: IT管理员、系统维护人员
- **特殊说明**: 不可删除,至少保留一个管理员用户

#### 数据分析员(analyst)
- **描述**: 负责数据分析和报告生成
- **权限范围**:
  - 首页:查看、导出
  - 事件管理:查看、导出
  - 聚合事件:查看
  - 人员分析:查看、导出
  - 事件主题:查看
  - 统计报告:查看、生成、导出
  - 月度报告:查看、创建、编辑
  - 智能分类:查看
- **适用人员**: 数据分析师、业务分析人员

#### 普通用户(user)
- **描述**: 基本的查看和操作权限
- **权限范围**:
  - 首页:查看
  - 事件管理:查看、创建
  - 聚合事件:查看
  - 人员分析:查看
  - 事件主题:查看
- **适用人员**: 一般业务人员

#### 只读用户(viewer)
- **描述**: 只能查看,无编辑权限
- **权限范围**:
  - 首页:查看
  - 事件管理:查看
  - 聚合事件:查看
  - 人员分析:查看
  - 事件主题:查看
  - 统计报告:查看
- **适用人员**: 外部观察者、临时访客

### 3.2.3 功能列表

#### 3.2.3.1 角色列表查看
**功能描述**: 以表格形式展示系统所有角色

**展示字段**:
| 字段名称 | 字段说明 | 数据类型 | 备注 |
|---------|---------|---------|------|
| 角色名称 | 角色显示名称 | String | 用于界面展示 |
| 角色编码 | 角色唯一标识 | String | 2-20位小写字母或下划线,创建后不可修改 |
| 角色描述 | 角色功能说明 | String | 可选 |
| 权限数量 | 该角色拥有的权限个数 | Integer | 蓝色标签展示 |
| 用户数 | 分配了该角色的用户数量 | Integer | 绿色徽章展示 |
| 状态 | 角色状态 | Boolean | 启用/禁用 |
| 创建时间 | 角色创建时间 | DateTime | - |

**交互功能**:
1. 支持分页展示
2. 支持按角色名称和编码搜索
3. 点击行左侧图标可展开查看权限详情
4. 权限详情按模块分组展示

#### 3.2.3.2 角色搜索
**功能描述**: 通过关键词快速查找角色

**搜索范围**:
- 角色名称
- 角色编码

**搜索规则**:
- 模糊匹配,不区分大小写
- 实时过滤

#### 3.2.3.3 添加角色
**功能描述**: 创建新的系统角色

**表单字段**:
| 字段名称 | 是否必填 | 验证规则 | 说明 |
|---------|---------|---------|------|
| 角色名称 | 是 | 非空字符串,不能重复 | - |
| 角色编码 | 是 | 2-20位小写字母或下划线,不能重复 | 创建后不可修改 |
| 角色描述 | 否 | - | - |
| 权限配置 | 是 | 至少选择一个权限 | 以树形结构展示 |

**权限选择器**:
- 以树形结构展示所有权限
- 支持按模块折叠展开
- 支持全选/取消全选
- 支持父子节点关联选择
- 默认全部展开
- 实时显示已选权限数量

**业务规则**:
1. 角色编码创建后不可修改
2. 角色名称和编码必须唯一
3. 至少选择一个权限
4. 新角色默认状态为"启用"

#### 3.2.3.4 编辑角色
**功能描述**: 修改已存在角色的信息

**可编辑字段**:
- 角色名称
- 角色描述
- 权限配置

**不可编辑字段**:
- 角色编码
- 创建时间

**业务规则**:
1. 编辑时预填充当前角色信息
2. 修改权限后,拥有该角色的所有用户权限立即更新
3. 系统预置角色的编码不可修改,但可以调整权限
4. 至少保留一个权限

#### 3.2.3.5 删除角色
**功能描述**: 从系统中删除角色

**业务规则**:
1. 删除前必须二次确认
2. 如果角色下有用户,不允许删除,需先移除所有用户的该角色
3. 系统预置的四个角色建议不允许删除(可配置)
4. 删除操作不可恢复
5. 删除时记录操作日志

**限制条件**:
- 用户数 > 0 时不可删除
- 系统预置角色不可删除(可选)

#### 3.2.3.6 角色权限详情
**功能描述**: 展开查看角色的权限明细

**展示方式**:
- 表格行展开
- 按模块分组
- 每个模块显示:
  - 模块标识(标签)
  - 该模块下的具体权限(标签列表)

### 3.3.3 功能列表

#### 3.3.3.1 权限列表查看

- 按模块分组,使用Collapse组件
- 每个模块面板头部显示:
  - 模块图标
  - 模块名称
  - 模块标识(标签)
  - 模块描述

- 默认全部展开

- 以表格形式展示该模块下的所有权限
- 表格列:权限名称、权限标识、权限描述、授权角色、角色数

**授权角色展示**:
- 显示拥有该权限的所有角色
- 角色以不同颜色标签展示
- 显示角色总数

#### 3.3.3.2 权限搜索
**功能描述**: 通过关键词快速查找权限

**搜索范围**:
- 权限名称
- 权限标识
- 权限描述

**搜索规则**:
- 模糊匹配,不区分大小写
- 实时过滤
- 只显示包含匹配权限的模块
- 无结果时显示空状态

#### 3.3.3.3 统计信息
**功能描述**: 展示权限体系的统计概览

**统计指标**:
| 指标名称 | 说明 | 展示方式 |
|---------|------|---------|
| 权限模块 | 模块总数 | 蓝色徽章 |
| 权限总数 | 所有权限数量 | 绿色徽章 |
| 系统角色 | 角色总数 | 橙色徽章 |
| 权限状态 | 系统状态 | 成功标签 |

## 6. 业务规则

### 6.1 密码规则
1. 密码最小长度:6位
2. 密码最大长度:20位
3. 推荐包含:大写字母、小写字母、数字、特殊字符
4. 密码使用bcrypt算法加密存储
5. 密码重置后强制用户首次登录修改

### 6.2 权限计算规则
1. 用户的最终权限 = 所有角色的权限并集
2. 用户拥有多个角色时,权限取并集而非交集
3. 权限修改立即生效,已登录用户需要重新加载权限

### 6.3 删除限制
1. 用户不能删除自己
2. 系统管理员账号(ID=1的admin)不允许删除
3. 至少保留一个系统管理员用户
4. 角色下有用户时不允许删除角色
5. 建议使用软删除(逻辑删除)

### 6.4 状态管理
1. 禁用用户立即生效,该用户的所有会话将被终止
2. 禁用角色不影响已登录用户,但新登录时生效
3. 系统管理员不允许被禁用
4. 用户不能禁用自己

### 6.5 唯一性约束
1. 用户名全局唯一
2. 邮箱全局唯一
3. 角色编码全局唯一
4. 权限标识全局唯一

## 7. 安全要求

### 7.1 认证与授权
1. 所有接口需要JWT token认证
2. Token过期时间:24小时
3. 支持刷新Token机制
4. 权限验证采用前后端双重验证

### 7.2 密码安全
1. 密码使用bcrypt加密,加密强度10
2. 禁止在日志和接口响应中暴露密码
3. 密码重置发送的邮件包含一次性链接
4. 支持密码强度检测

### 7.3 操作审计
1. 所有敏感操作记录到操作日志
2. 日志包含:操作人、操作时间、操作内容、IP地址
3. 日志保留期限:至少6个月
4. 支持日志查询和导出

### 7.4 数据安全
1. 用户数据采用软删除,保留6个月后物理删除
2. 敏感字段(手机号、邮箱)加密存储
3. 定期备份数据库
4. 防止SQL注入和XSS攻击
