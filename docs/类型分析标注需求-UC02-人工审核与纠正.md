# UC02-人工审核与纠正

### 1. 用户故事
As a 业务审核人员, I want to在模型无法高置信度判断时进行人工确认与纠正, So that 分类结果在入库前保持准确并形成反馈闭环。

### 3. 验收标准
- LLM返回置信度低于设定阈值或存在多类别并列时, 事件自动进入待审核队列, 并附带模型输出与解释。
- 审核界面需支持查看原始事件描述、候选类别、置信度、模型解释及历史处理记录。
- 审核人员可选择正确类别或手动录入新类别说明, 并提交处理备注; 提交后系统同步更新事件分类结果。
- 每次人工纠正会记录处理人、处理时间、修改前后类别, 并将纠正数据回传模型调优组件。
- 多人并发审核时状态锁定与冲突提示生效, 保证不会出现重复或覆盖提交。

### 4. 风险评估
- 审核工作量大 → 通过过滤、排序与批量处理功能提升效率。
- 人工纠正与模型迭代脱节 → 建立反馈接口, 定期将纠错样本用于模型再训练。
- 审核权限管理不严导致误操作 → 结合角色权限控制与操作日志审计。
