## 第一期：核心统计维度（优先级高）

### 1. 聚合规模分析

**功能描述：**
- 聚合事件规模分布（包含2-5个事件、6-10个、10个以上）
- 平均聚合度（每个聚合平均包含多少个事件）
- 最大聚合事件TOP10（识别重点问题）

**可视化方式：**
- 柱状图：展示不同规模区间的聚合事件数量
- 饼图：展示各规模区间占比
- 排行榜：TOP10最大规模聚合事件

### 2. 时间演变分析

**功能描述：**
- 聚合事件生命周期分布（从首次出现到最后一次的时间跨度）
- 事件聚集趋势图（按时间轴显示事件如何聚集）
- 高发时段分析（识别问题爆发的时间规律）

**可视化方式：**
- 时间轴：展示聚合事件的演变过程
- 折线图：展示不同时段的聚合事件数量趋势
- 热力图：按小时/天/周/月展示高发时段

### 3. 地域热点分析

**功能描述：**
- 街镇聚合事件分布地图/热力图
- 高发区域TOP排名
- 地域扩散分析（是否从一个区域蔓延）

**可视化方式：**
- 地图热力图：直观展示各区域聚合事件密度
- 区域排行榜：TOP10高发街镇/社区
- 扩散路径图：展示问题的空间传播路径

### 4. 主题/分类分析

**功能描述：**
- 聚合事件的分类分布（矛盾纠纷、城市管理等占比）
- 主题词云（提取高频关键词）
- 跨分类聚合分析（是否涉及多个分类）

**可视化方式：**
- 饼图/环形图：展示各分类占比
- 词云图：展示高频主题词
- 桑基图：展示跨分类关联

## 第二期：关联关系和处理效果分析

### 一、关联关系分析

#### 1. 多维关联网络图

**核心功能：** 可视化展示事件之间的关联关系

**数据结构：**
- **节点**：代表单个事件
- **边**：代表关联关系（可以是地点、人员、主题等）
- **节点大小**：反映事件重要程度或影响范围
- **边的粗细**：反映关联强度

**交互功能：**
- 点击节点查看事件详情
- 筛选关联类型（地点关联/人员关联/主题关联）
- 高亮显示选中事件的所有关联事件
- 支持缩放、拖拽

**示例场景：**
```
某小区停车纠纷 → 关联 → 邻里纠纷 → 关联 → 物业纠纷
（都发生在同一小区，涉及同一批业主）
```

#### 2. 人员关联分析

**一人多事排行榜**

| 排名 | 姓名 | 事件数 | 主要类型 | 趋势 |
|------|------|--------|----------|------|
| 1 | 张某 | 15 | 债务纠纷 | ↑ 上升 |
| 2 | 李某 | 12 | 邻里纠纷 | ↓ 下降 |

**人员事件时间轴**
```
├──●──────●────●──────●──────────────►
  1月    2月   3月   4月
```
- 首次投诉
- 重复投诉频率
- 投诉类型变化

**人员画像**
- 投诉习惯（时段、渠道）
- 问题诉求（关键词提取）
- 沟通特征（情绪、态度）
- 处理建议（预设应对方案）

**核心指标：**
- 重复投诉人数及占比
- 平均投诉频次
- 投诉类型分散度（是否集中在某个领域）
- 投诉周期（间隔时间）
- 解决满意度

**预警规则：**
- 30天内投诉超过5次 → 重点关注
- 投诉类型突然改变 → 可能问题升级
- 投诉频率突然增加 → 可能矛盾激化

#### 3. 地点关联分析

**一地多事排行榜**

| 地点 | 事件数 | 主要类型 | 状态 |
|------|--------|----------|------|
| XX小区A栋 | 28 | 停车+噪音 | 3未解决 |
| XX街道 | 23 | 市容环境 | 1未解决 |

**地点事件分布图（桑基图）**
```
小区A ─┬─ 停车纠纷 (15)
       ├─ 噪音投诉 (8)
       └─ 物业纠纷 (5)

商业区 ─┬─ 环境卫生 (12)
        └─ 占道经营 (9)
```

**地点问题演变趋势**
- 问题是否集中在特定区域？
- 是否有扩散趋势？
- 新问题还是老问题？

**空间分析维度：**
- 空间聚集度（是否高度集中）
- 空间扩散速度（从一个点到周边）
- 空间关联性（相邻地点问题相似度）
- 空间热点迁移（热点区域的变化）

#### 4. 主题关联分析

**事件主题关联矩阵**

|        | 停车 | 噪音 | 物业 | 邻里 | 债务 |
|--------|------|------|------|------|------|
| 停车   | -    | 45   | 32   | 12   | 3    |
| 噪音   | 45   | -    | 28   | 56   | 1    |
| 物业   | 32   | 28   | -    | 23   | 8    |
| 邻里   | 12   | 56   | 23   | -    | 15   |
| 债务   | 3    | 1    | 8    | 15   | -    |

*数字表示：两个主题同时出现的次数*

**典型关联模式**
- **停车纠纷 + 邻里纠纷** (45次)
  → 因停车位引发的邻里矛盾

- **噪音投诉 + 邻里纠纷** (56次)
  → 因噪音引发的邻里矛盾

- **物业纠纷 + 停车纠纷** (32次)
  → 物业管理停车位不当

**分析价值：**
- 发现问题连锁反应（A问题可能引发B问题）
- 识别根源问题（哪个问题是其他问题的导火索）
- 优化处理策略（解决根源问题可能同时解决多个问题）

#### 5. 跨部门关联分析

**责任部门协同情况：**
- 哪些聚合事件需要多部门协同？
- 协同效率如何？
- 是否存在推诿扯皮？
- 部门间移交次数统计

## 第三期：预警与预测功能

### 一、实时预警系统

#### 1. 多维度预警规则引擎

**智能预警看板**

```
┌─────────────────────────────────────────┐
│ ⚠️ 智能预警看板                          │
├─────────────────────────────────────────┤
│ 当前预警  [ 23 条 ]                      │
│                                          │
│ 🔴 高风险 (5)                            │
│ ├─ XX小区聚合事件激增                   │
│ │  • 7天内新增12起投诉                   │
│ │  • 涉及68人，情绪激烈                  │
│ │  • 建议：立即介入，组织现场协调会      │
│ │                                        │
│ ├─ 张某投诉频率异常                     │
│ │  • 5天内投诉8次                        │
│ │  • 投诉级别升级（三级→一级）          │
│ │  • 建议：专人对接，了解诉求            │
│                                          │
│ 🟡 中风险 (12)                           │
│ ├─ 南门街道事件聚集趋势                 │
│ │  • 3个聚合事件可能关联                 │
│ │  • 建议：排查是否同一根源               │
│                                          │
│ 🟢 低风险 (6)                            │
│ └─ XX问题出现苗头                       │
│    • 近期相关投诉增加20%                │
│    • 建议：持续关注                      │
└─────────────────────────────────────────┘
```

#### 预警类型与触发条件

##### A. 聚集性预警

**触发条件：**
- ✓ 同一地点/主题，短时间内（3天）新增事件≥5起
- ✓ 涉及人数≥20人
- ✓ 事件级别≥二级

**预警级别：**
- 🔴 **紧急**：3天内≥10起，涉及≥50人
- 🟡 **关注**：3天内5-9起，涉及20-49人
- 🟢 **提示**：3天内3-4起，涉及10-19人

**应对建议：**
- 立即组织现场调研
- 成立专项工作组
- 启动应急预案

##### B. 人员行为预警

**触发条件：**
- ✓ 7天内同一人投诉≥5次
- ✓ 投诉级别升级（三级→二级→一级）
- ✓ 投诉内容出现激烈情绪词汇

**预警信号：**
- **频次激增**：投诉间隔<1天
- **级别升级**：连续升级2次以上
- **渠道升级**：从普通渠道到信访/媒体
- **情绪升级**：出现"上访""媒体曝光"等关键词

**应对建议：**
- 专人对接，主动沟通
- 了解核心诉求
- 制定个性化解决方案
- 必要时领导约谈

##### C. 区域热点预警

**触发条件：**
- ✓ 某街道/社区事件密度超过均值50%
- ✓ 新增聚合事件数量环比增长≥30%
- ✓ 出现跨区域扩散迹象

**识别标准：**
- 空间聚集系数 > 0.7
- 新增速度 > 历史均值1.5倍
- 影响范围持续扩大

**应对建议：**
- 区域排查，找出根源
- 街道层面统一部署
- 防止问题扩散

##### D. 主题升级预警

**触发条件：**
- ✓ 某类问题聚合规模增长≥40%
- ✓ 从低级别向高级别演变
- ✓ 出现群体性事件苗头

**监测指标：**
- **问题规模**：同比/环比增长率
- **级别分布**：高级别事件占比
- **群体特征**：涉及人数、组织性

**应对建议：**
- 专题研究该类问题
- 制定系统性解决方案
- 必要时政策调整

##### E. 复发性预警

**触发条件：**
- ✓ 同一问题30天内复发≥3次
- ✓ 问题未得到根本解决
- ✓ 群众满意度持续下降

**评估标准：**
- 复发频率
- 复发间隔缩短
- 投诉强度增加

**应对建议：**
- 重新评估处理方案
- 查找根源问题
- 建立长效机制

#### 2. 预警消息推送

**发送对象：**
- 责任部门负责人（实时短信/微信）
- 街道领导（每日摘要邮件）
- 区级领导（重大预警专报）

**通知方式：**
- 🔴 **高风险**：立即电话+短信+系统弹窗
- 🟡 **中风险**：短信+系统通知
- 🟢 **低风险**：系统通知

**升级机制：**
- 2小时未响应 → 上级领导
- 24小时未处理 → 区级领导

### 三、预测技术实现

#### 1. 数据特征工程

**时间特征：**
- 周几、月份、季节
- 是否节假日
- 是否重大活动期间

**空间特征：**
- 街道、社区编码
- 人口密度
- 历史热点区域标记

**事件特征：**
- 事件类型、级别
- 投诉渠道
- 处理时长
- 是否复发

**聚合特征：**
- 聚合规模
- 聚合生命周期
- 涉及人数
- 情绪指数（文本分析）

**关联特征：**
- 地点关联度
- 人员关联度
- 主题相似度

#### 2. 预测算法选择

**短期预测（1-7天）：**
- ✓ ARIMA 时间序列模型
- ✓ Prophet (Facebook开源)
- ✓ 移动平均

**中期预测（8-30天）：**
- ✓ LSTM 神经网络
- ✓ XGBoost 集成学习
- ✓ 随机森林

**长期预测（1-3月）：**
- ✓ 趋势分解
- ✓ 季节性调整
- ✓ 多元回归

#### 3. 模型评估与优化

**评估指标：**
- MAE (平均绝对误差)
- RMSE (均方根误差)
- MAPE (平均绝对百分比误差)
- 预测准确率

**模型迭代：**
- 每周重新训练
- 新数据持续反馈
- A/B测试不同模型
- 人工修正 + 机器学习
