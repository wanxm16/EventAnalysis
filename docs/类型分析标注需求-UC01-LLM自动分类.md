# UC01-LLM自动分类

### 1. 用户故事
As a 物业纠纷分析专员, I want the system to利用LLM在10秒内完成事件类型识别并输出解释说明, So that 我能快速获取分类结果并理解判定依据。

### 3. 验收标准
- 系统在事件入库或更新时自动触发LLM分类流程, 并在10秒内返回预测类别与置信度。
- 分类结果必须映射到预设的五类纠纷标签, 无法匹配时自动标记为“其他”。
- 每次分类需生成包含关键语句引用或规则命中说明的解释文本, 与分类结果一同存储。
- 系统记录模型版本、请求时间、响应时间、置信度及原始提示词, 以支持追溯与质量监控。
- 在小于10个并发调用场景下, 分类接口保持稳定, 超时或失败时提供可重试机制并告警。

### 4. 风险评估
- LLM准确率不足 → 引入持续评估体系, 结合人工审核反馈迭代提示词与模型。
- 响应时长波动超过10秒 → 采用异步队列与缓存机制, 并在高峰时扩容计算资源。
- 解释说明不符合监管或审计要求 → 设计统一模板并限制信息来源范围, 保证可读性与合规性。
