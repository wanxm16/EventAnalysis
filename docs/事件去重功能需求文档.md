# 事件去重功能需求文档

## 1. 项目概述

### 1.1 项目背景
在事件管理系统的聚类分析中，经常出现同一事件被重复上报或相同问题被多次反映的情况。这些重复事件会影响数据分析的准确性，增加处理人员的工作负担，并可能导致资源配置的不合理。为了提升数据质量和分析效率，需要在聚类详情页面实现智能去重功能，自动识别和合并描述相同的重复事件。

### 1.2 产品目标
- 自动识别聚类中描述相同的重复事件，减少数据冗余
- 提供直观的重复事件标识和详情查看功能
- 保持数据完整性，所有原始事件信息可追溯
- 支持用户灵活控制去重功能的启用状态
- 提升事件分析的准确性和处理效率

### 1.3 目标用户
- **数据分析师**：需要准确的事件统计和趋势分析
- **处理人员**：希望避免重复处理相同问题
- **管理人员**：需要了解真实的事件规模和分布
- **系统维护人员**：负责数据质量管理和优化

## 3. 功能设计

### 3.1 去重算法设计

#### 3.1.1 核心去重逻辑
```javascript
function deduplicateEvents(events) {
  // 按事件描述分组
  const groups = {};
  events.forEach(event => {
    const desc = (event.事件描述 || '').trim();
    if (!desc) {
      // 无描述事件单独处理
      groups[`no_desc_${event.事件编号}`] = [event];
      return;
    }
    if (!groups[desc]) {
      groups[desc] = [];
    }
    groups[desc].push(event);
  });

  // 生成去重结果
  const result = [];
  Object.entries(groups).forEach(([desc, eventsInGroup]) => {
    if (eventsInGroup.length === 1) {
      // 单个事件，直接添加
      result.push({
        ...eventsInGroup[0],
        isDuplicate: false,
        duplicateCount: 1,
        duplicateEvents: eventsInGroup
      });
    } else {
      // 多个重复事件，选择最早的作为代表
      const sorted = eventsInGroup.sort((a, b) =>
        parseTime(a.上报时间) - parseTime(b.上报时间)
      );
      result.push({
        ...sorted[0],
        isDuplicate: true,
        duplicateCount: eventsInGroup.length,
        duplicateEvents: sorted
      });
    }
  });

  return result;
}
```

#### 3.1.2 去重策略选择
- **精确匹配**：当前采用描述字段精确匹配
- **预留扩展**：预留接口支持未来的模糊匹配算法
- **空值处理**：无描述事件不参与去重
- **排序逻辑**：按上报时间升序排列，最早的作为代表
